📖 ZI Git — Полная инструкция

Загрузчик готовых сборок из GitHub Actions. Версия 2.6.

📥 1. Установка

1 Скачайте ZI-Git.apk из релизов GitHub или через само приложение (вкладка «Релизы» → ZI-Git.apk).
2 Откройте скачанный файл на телефоне.
3 Разрешите установку из этого источника (Android спросит один раз).
4 Если Play Protect предупреждает — нажмите «Установить всё равно» (это нормально для APK вне Google Play).

Требования: Android 8.0+ (API 26), интернет.

🔑 2. Подключение к GitHub

Для скачивания артефактов нужен токен GitHub. Без него работают: просмотр запусков, релизы публичных репозиториев и ZIP-исходники.

Как создать токен

Вариант 1: Classic-токен (проще всего)

1 В приложении нажмите ⋮ → Токен GitHub
2 Нажмите Создать classic токен (repo + workflow) — откроется GitHub
3 Галочки repo и workflow уже проставлены → Generate token
4 Скопируйте токен (ghp_…) и вставьте в приложение

Вариант 2: Fine-grained токен

1 GitHub → Settings → Developer settings → Fine-grained tokens → Generate
2 Repository access → «All repositories»
3 Repository permissions:
  • Metadata: Read-only (обязательно)
  • Actions: Read-only
  • Contents: Read-only
  • Administration: Read and write (для создания/редактирования репо)
4 Save → скопируйте → вставьте в приложение
⚠️ Приватные репозитории видны только токену с доступом к ним. Если список короткий — проверьте токен: ⋮ → Токен GitHub → «Проверить, что видит токен».

Список запусков

Каждый запуск показывает:

  • Название запуска (заголовок workflow)
  • Бейдж статуса: success failure ⏳ in_progress queued
  • Детали: номер (#42), workflow, ветка, коммит (7 символов), время
  • Артефакты: количество и общий размер

ЖёлтыйПредупреждения: warning:, deprecated
ЗелёныйУспех: ✓, build successful
Голубой + жирныйЗаголовки: Run …, ==>

🔄 12. Обновления приложения

Автоматическая проверка

При каждом запуске приложения (тихо, в фоне, не чаще раза в 4 часа). Если есть новая версия — появится диалог.

Ручная проверка

1 ⋮ → О приложении
2 Проверить обновления

Диалог обновления

Показывает: новую и текущую версию, размер APK, дату, описание изменений.

КнопкаЧто делает
Скачать и установитьСкачивает APK с прогрессом → запускает установку
На GitHubОткрывает страницу релиза в браузере
ПозжеЗакрыть диалог
💡 Обновления ставятся поверх текущей версии — данные не теряются. Подпись постоянным ключом.
